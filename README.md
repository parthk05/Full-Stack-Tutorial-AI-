# Full-Stack-Tutorial-AI

Step-wise guided lessons for software development with AI. Each chapter ships a **mini-project** on one growing product (**Helix** → **GroundGate**). Every chapter ends with an **open problem** that the next chapter exists to solve — so you feel why each advancement happened.

## AI pathway

Start here: **[ai/00-roadmap.md](./ai/00-roadmap.md)**

| Chapter | Mini-project | You ship… | Next chapter exists because… |
|---------|--------------|-----------|------------------------------|
| [01](./ai/01-prompting-and-reliability.md) | Helix Prompt Desk | Prompt strategies over FastAPI | Answers invent facts; free text is unreliable |
| [02](./ai/02-tools-and-structured-outputs.md) | Helix Structured Desk | Typed outputs + stub tools | Tools can’t see long handbook docs |
| [03](./ai/03-rag-and-context-engineering.md) | Helix Source Desk | RAG + citations + context packing | One-shot RAG isn’t a business pipeline |
| [04](./ai/04-ai-workflows.md) | Helix Flow | LangGraph intake + HITL | Fixed graphs struggle with open-ended goals |
| [05](./ai/05-agents-multiagent-mcp.md) | Helix Agent | Agents, multi-agent, MCP | Autonomy without measurement regresses silently |
| [06](./ai/06-llmops.md) | Helix Ops | LangSmith + Langfuse + evals | Measuring ≠ fail-closed governance |
| [07](./ai/07-llm-eval-governance-capstone.md) | GroundGate | Faithfulness + citation gates (pharma/finance) | Capstone / resume project |

**Stack:** Python, FastAPI, LangChain / LangGraph, LangSmith, Langfuse.

This AI track is **standalone** — it does not depend on any other tutorial project in the repo.
